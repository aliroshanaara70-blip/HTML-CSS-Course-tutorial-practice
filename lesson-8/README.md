## Lesson 8 Exercises: Display Block and Inline-Block

- **`8a.html`**: Stacked two text inputs vertically using `display: block`.
- **`8b.html`**: Placed a fixed-width paragraph and two buttons on the same line using `display: inline-block` and `vertical-align: middle`.
- **`8c.html`**: Created a Google search layout by positioning the logo above the search bar with block display and margins.
- **`8d.html`**: Challenge exercise building a Sign Up form with inline name fields, a block email field, and a full-width button.
- **`8e.html`**: Challenge exercise recreating an Uber request-a-ride form with stacked location inputs and action buttons.
